# Prompt 00 — Auditoría y bootstrap

Lee `AGENTS.md` y el kit completo. No implementes features todavía.

1. Clona `https://github.com/devmoreir4/godot-3d-multiplayer-template` en el tag/release `v2.0.0`; no uses la rama más reciente sin fijar commit. Si el tag no existe, detente y reporta.
2. Lee LICENSE, README, assets/ATTRIBUTIONS, scripts y escenas. El código MIT no cambia la licencia de assets de terceros.
3. Ejecuta Godot 4.7.2 Standard headless: importación, apertura y arranque básico.
4. Prueba servidor headless con dos clientes o prepara una prueba reproducible que pueda ejecutarse en CI.
5. Confirma qué funciones son reales. Recuerda: el ataque documentado de muestra es solo animación visual, no daño.
6. Crea repo propio RPG-LBA (o usa el repo destino dado por el responsable), branch main protegida y branch de trabajo.
7. Añade estructura de docs, AGENTS.md y CI de importación. No descargues paquetes grandes aún.
8. Crea inventario de recursos con licencia y plan de migración de cámara.

Entrega matriz: reutilizar / modificar / sustituir / no usar. No cambies el juego original hasta que la auditoría haya sido aprobada.
