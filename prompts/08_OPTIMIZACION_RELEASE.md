# Prompt 08 — Optimización Android y release candidate

Implementa perfiles Low/Medium/High/Adaptive en Compatibility Renderer. Medir CPU/GPU frame time, memoria, temperatura y batería en dispositivos reales. Prueba Redmi 9C y al menos un dispositivo medio/alto; registra modelo exacto, variante RAM, Android, driver, renderer y ajustes. Mantén Low como objetivo de compatibilidad. No afirmar “30 FPS estables” sin una sesión sostenida y una muestra medida.

Revisa licencias/atribuciones, seguridad de RPC, transacciones, migraciones, backups, logs, crash report, consentimientos, idioma y créditos. Compila APK debug en PR/manual y release firmado solo con secrets de GitHub. Genera notas de versión y release candidate. No publicar online hasta que exista alojamiento, dominio/endpoint, firewall, monitorización, backups y política de soporte.
